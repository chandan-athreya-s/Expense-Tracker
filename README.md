# Expense Tracker

I wanted to build something that could solve a real problem in my everyday life while also helping me grow as a software developer.

As I started managing my own expenses, I realized that I wasn't consistently keeping track of where my money was going. Small expenses like chai, snacks, travel, and other everyday purchases can easily add up without being noticed.

At the same time, I wanted to move beyond simply learning technologies through tutorials. I wanted to **build something real, use it myself, make mistakes, and learn from them.**

So this project was born from two simple goals:

### Track My Spending

Build something that helps me record my everyday expenses, understand my spending habits, and become more mindful about where my money goes.

### Learn by Building

Use the project as a hands-on way to learn and practice a full-stack technology stack:

- React
- Java
- Spring Boot
- PostgreSQL
- REST APIs
- Git

I don't want this to be just another project sitting on my GitHub. I want it to be something I actually use in my daily life — something that grows alongside my skills.

> **One project. Two goals: understand where my money goes, and become a better developer.**

**Currently under development.**
